# AI contributor rules

`README.md` is a human-owned public introduction. It is not a place for internal changelogs, audit notes, optimization hypotheses, script names inventories, or auto-generated status.

**Never change, rename, delete, reformat, translate, regenerate, or automatically synchronize `README.md` unless the human repository owner explicitly requests a change to README in the current task.** Script changes, driver updates, release changes, and other documentation work do not imply permission.

If the owner explicitly requests a README edit, change only what was requested and show the exact diff. Do not bypass repository permissions, owners, reviews, or rulesets.

Put engineering notes in `docs/`. These instructions govern agents but do not technically enforce GitHub write restrictions.
